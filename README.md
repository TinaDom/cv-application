# CV Application

A React-based CV Application built as part of [The Odin Project](https://www.theodinproject.com/).

## Overview

This application allows users to create a CV by entering their personal information, educational background and work experience. Each section can be submitted, edited or cleared independently.

## Features

- General Information section for personal details
- Education section for academic qualifications
- Experience section for professional work history
- Controlled form inputs using React state
- Form validation using required fields
- Submit functionality to display entered information
- Edit functionality to update submitted information
- Clear Form functionality to reset individual sections
- Current employment option with conditional end date
- Responsive layout for different screen sizes

## Technologies

- React
- JavaScript
- HTML
- CSS
- Vite

## Getting Started

### Prerequisites

Make sure you have Node.js and npm installed.

### Installation

Clone the repository:

```bash
git clone https://github.com/TinaDom/cv-application.git
```

Navigate into the project directory:

```bash
cd cv-application
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open the local URL provided by Vite in your browser.
